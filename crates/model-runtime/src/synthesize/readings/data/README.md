# Embedded reading data

This directory holds the embedded data for `model_runtime::synthesize::readings` (per-character reading annotation for heteronyms before TTS synthesis; architecture design §6.1, "Reading annotation"). It is carried over unchanged from v2 `ccut-tts/src/text/data/` (byte-identical).
`*.z` files are zlib (deflate) compressed. They are compiled into the binary via `include_bytes!` and decompressed on first use. They are generated by `scripts/dev/gpt-sovits-text/gen_heteronyms.py` in the v2 repository (`cuccut-app`). **Do not edit by hand**; the generator was not carried over to v3.
`context_heteronyms.txt` is a hand-reviewed list. After changing it, re-run the script (the script checks that every character appears in the heteronym table).

## Regenerating

Run this in the v2 repository (`cuccut-app`):

```bash
python scripts/dev/gpt-sovits-text/gen_heteronyms.py
```

For the venv, see "环境" (Environment) in `scripts/dev/gpt-sovits-text/README.md` there (only pypinyin is needed). After changing the data, update the SHA-256 values in the table below as well: `cargo test -p model-runtime synthesize::readings` cross-checks them.
