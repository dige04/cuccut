The actual deliveries of each milestone that differ from the literal text of this document are recorded item by item in §13.1 (intentional limitations) and §17 (not implemented). Several deviations from the original plan deserve a separate mention:

- M2 did not implement `segment-only` small-model routing. It depends on the per-kind model routing of §9.4, which has not been implemented (§17).
- M3 did not do the `⏸` threshold unification. This was intentional (§13.1).
- M4 did not do the `ccut glossary` subcommand (it was already marked as optional).
- The scope of M5 was narrowed. It covers only wrap-up cleanup, documentation and multi-surface sync, and worker-side docs. **Deprecating the JSON contract and connecting `refine-align` to the file contract are both outside M5.** The former first requires the documentation channel in §9.1 and removing the brief dual-write in §13.1 (item 1); the latter first requires reconciling refine's own retry accounting. Both are deferred, and their entry points are recorded in §17.
