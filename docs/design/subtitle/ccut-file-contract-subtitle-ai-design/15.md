# 15. Testing and Acceptance

> From [CucCut File-Contract Subtitle AI Pipeline Design (File-Contract Pipeline, v0.3)](../ccut-file-contract-subtitle-ai-design.md)

- **Pure-function golden tests**: input/output comparison for rendering, parsing and diff. A set of negative fixtures is required: deliberately missing id, duplicate id, overlapping conflicts, illegal rowspan, truncated page, multiple fences, frozen sentence edited.
- **Property tests** (three minimum requirements):
  1. For any words sequence, after a render→parse round-trip, the id set and order are unchanged;
  2. For any valid align table, the parsed pieces satisfy contiguity + non-overlap + full coverage;
  3. For any polish output, after rebind, `join_word_texts(words)` equals the normalized output.
- **Dual-path shared regression**: the same fixture set must cover both agent file submissions and raw provider responses (including fences, broken tags, missing ids, overlapping conflicts). Testing only one execution path is not allowed.
- **End-to-end**: full pipeline on the p850/p130 benchmark projects, one pass each for stale-only and timeline.
- **Performance acceptance**: compare call count, total tokens and wall-clock time against the current baseline; CJK counting-scheme stress test (§12); quality non-regression verification for translation and alignment on an 8000-word page.

**M1–M4 coverage status**: pure-function golden tests, negative fixtures, dual-path shared regression, and `filepipe` round-trip comparison have all landed. Besides the core unit tests in `provenance.rs`, host-side end-to-end cases for provenance have also landed (`translation_provenance_round_trips_and_detects_term_changes` in `core/crates/ccut-kernel/src/cmd/ai/tests.rs`: it actually reads and writes `ai/state/translation.<lang>.json`, covering three cases: a term rename hits only the related sentences, a missing ledger, and `--no-brief` with no basis). **Not yet done is the performance acceptance**: the call count/token/wall-clock comparison in the last item of this section and the CJK stress test have not been run, so all numbers in §12 and §17.1 are still initial design values rather than measured calibrated values.
