# 13. Comparison with voice-ink and deliberate differences

> From [ccut transcript post-processing AI pipeline design (polish / segmentation / chaptering / translation / subtitle alignment)](../ccut-ai-pipeline-design.md)

| Dimension | voice-ink | This design | Reason for difference |
| --- | --- | --- | --- |
| Word timebase | Timeline time (document and timeline are one) | **Media source time** (§18) | One transcript is shared by multiple composed documents; mapping goes through the clip (format spec §18.6) |
| Stage state | `doc.stageStamps` stored in the editor document | The transcript's `stages` field + `ai/` artifact directory | The transcript is a standalone document (§18); state travels with it |
| Translation persistence | `doc.trans[lang][key]` (mixed cue/group keys) | Each source's `trans[lang][sentenceId]` is the authoritative full translated sentence; `transAlign` is only a display overlay; timeline routing does not become a third source of truth | Sentence keys are unified; cut/reuse only changes the projection and visible word stamps |
| LLM layer | Direct provider calls only (inside the GUI) | **Dual execution modes**: provider / agent reply loop | An existing decision in CLI design §8; CI and agent sessions share one contract |
| Segmentation output | `paraPins` → config | `paraBreaks` override table (§18.4) | Reuses the override table defined in the spec; adds no new mechanism |
| Implementation language | Swift (embedded in the GUI) | Rust `ccut-flow-core` (pure logic) + CLI host | The core/host layering mirrors the speech side; reused across all three platforms |
| Progress | `flow-live.json` + kqueue | Same structure + `task watch --jsonl` | Adds a streaming consumption entry point; the GUI can still watch the file |

**Mechanisms inherited verbatim (unchanged)**: FNV-1a dual fingerprints and their division of purpose; ⏸/⏹ soft markers;
paging rank checkpoints + carry-over; atom-LCS mapping and the 0.7/0.75 thresholds; rebind's “LCS word preservation + weight
interpolation”; the five-tier segmentation ladder and “boundary drift is tolerated, text never lies”; the chapter NDJSON
contract and six-step cleaning; compact translation echo and resume by sentence id; group-level stale + paragraph-level
rerun; word-time normalization's “at least 1 tick per word” floor; repair's “time operations do not change the
fingerprint”; “refinement never invalidates a completed transcript”; three structural constraints: json_object +
fence-strip + semantic validation; “non-retryable errors abort the entire run”.
