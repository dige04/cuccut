# 2. Invariants (red lines)

> From [CucCut File-Contract Subtitle AI Pipeline Design (File-Contract Pipeline, v0.3)](../ccut-file-contract-subtitle-ai-design.md)

Everything below is inherited from the current architecture; the file-based refactor **must not touch** any of it:

- **Source-of-truth model**: `words[]` is the only text and timing truth. Cue/Sentence/Para are always derived projections. The sparse override tables `breaks`/`paraBreaks`/`hidden` are keyed by word id. `trans[lang][sid]` is the sentence-level translation truth. `transAlign[lang][sid]` is only a display-segmentation overlay. The invariant `normalize(concat(pieces.text)) == normalize(trans)` must hold, and the write order to disk is `trans` first, then `transAlign`.
- **Five disciplines**: absolute timestamps never enter the LLM (relative durations and budget conversions are carried as attributes); deterministic validation rather than trust in prompts; tiered degradation, where the whole never fails (except 401/403/404); fingerprint-driven dirty detection; page boundaries are not persisted, and resumable runs rely on deterministic re-derivation.
- **Alignment order**: first freeze the translation pieces by target-language naturalness, then map contiguous source word ranges. Source Cues, source Cue boundaries, and the `breaks` table must not enter the payload and must not be back-inferred.
- **Manual layout takes priority**: `ensure_balanced_cue_layout` lays out balanced breaks only when `doc.breaks` is empty (the current early return in `layout.rs`). A stale `asrLayout` stamp means a manual layout intervention exists. Any degradation path, including the deterministic fallback in §6.6, must not silently re-lay out the layout when manual segment pins or line breaks exist. Explicit `--segment`/`--repair` are the exception.
- **Write ownership**: transcript, stage stamps, and fingerprints can only be written through `ccut` / `ccut serve` / apply scripts. The `ai/` artifact header (or manifest) carries a fingerprint, and readers must verify it before using the artifact.
- **One copy of validation**: the lint at agent submission and the validate on the provider path must be the same core function. **M1–M4 implementation decision**: the *arithmetic* of the reordered rewrite-magnitude guardrail has been merged into the single implementation `split.rs::reordered_rewrite_exceeds`, shared by all three call sites. However, the provider acceptance check (`align.rs:4721`) and the agent submission-time lint (`align.rs:5410`) remain two call sites with two byte-identical failure strings. The criterion is unified; the call sites are not (§13.1).
- **Reuse list** (carried over directly at the code level): `rebind.rs`/`lcs.rs` atom-level LCS rebinding; `atomize.rs` (including `word_count`); `seam.rs` seam lint; `split.rs` deterministic segmentation and the three `TransParams` thresholds; `fingerprint.rs`; `sentence.rs` derivation and `stale_sentences`; `markers.rs` pause markers; the `complete_batch_retry_with` skeleton of "retry only failed units + streaming on_ready"; `ProjectLock` + `save_doc` per-unit checkpoint; and the tasks/ lease system.
