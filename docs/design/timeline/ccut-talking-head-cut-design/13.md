# 13. Web Landing Reconciliation (2026-09-07)

> From [CucCut talking-head cut technical plan (prototype rounds 192–197 → core / serve / App v2 / Web)](../ccut-talking-head-cut-design.md)

This round completes the real runtime chain on top of the existing Web wiring, without changing the CLI / serve protocol or the data format.

| Audit finding | Final implementation |
|---|---|
| Web force-cast WASM methods that did not exist, so the cut entry point was always disabled | API 23 formally exports `cutModeProject/SelectionSpan/TimelineOverlay/Summary/Resolve/Key`, `paraTokens/tokenAt`; field adaptation is concentrated at the Web boundary |
| Rust `state/op/action` and Web `kind`, UTF-16 ranges and selection fragment shapes differed | Real serialization adaptation; selection explicitly returns all `MappedEvent`s, with no JS time-algorithm fallback |
| "Restore all" for cut segments wrongly went through review restore | Shared `CutAction::RestoreAll` produces one batch `restoreCut`, including manual cuts; App reuses it in sync |
| Cut seams / suggestions were still on the source-view axis, so positions were wrong after trim and speed change | Shared `mapped_timeline_overlay` projects by the actual clip; repeated use of the same main material draws each time; App / Web in sync |
| ⌘↵ did not pass pending context; leaving the script or clicking the timeline did not clear selection | Added shortcut context and selection lifecycle; cut shortcut does not fire while a drag-selection is in progress |
| Receipt restore could revoke an entire batch, including accepted cuts | Web restores only the dismissed ids of that batch; when ignoring the toast, prefer server `changed[]`; accepts where all were skipped offer no document undo |
| Summary still depended on non-existent text/detail returns | Shared summary counts + App same-source i18n copy; stale suggestions disable accept and prompt a rescan |

The existing virtual paragraphs, clean default entry, post-cut optimistic projection, WebSocket review refresh, AI card settings, source-clock preview and undo queue continue to use the original implementation and have been included in the relevant regression checks.
Detailed commands, results, and the repo-wide checks that did not pass are in [`apps/web/docs/talking-head-cut.md`](../../../../apps/web/docs/talking-head-cut.md).
