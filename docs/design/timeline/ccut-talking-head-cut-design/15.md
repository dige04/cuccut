# 15. Web Implementation Ledger (Rounds 196–201)

> From [CucCut talking-head cut technical design (prototype rounds 192–197 → core / serve / App v2 / Web)](../ccut-talking-head-cut-design.md)

The rounds 192–193 baseline for `apps/web` is in §13. The status below records later implementation by prototype round, reusing the shared criteria of `ccut-editor-core`. API 24–26 already export the fold mapping, hidden text, compose grouping, cue-cut impact, stale-sentence filtering and tool progress.

**W-13 update (2026-09-07)**: W-12 / W-13 are complete. The requirement for seam markers in the closed state of W-1 / W-2 has been superseded by round 200's “关闭不画任何剪口” (closed state draws no cut marks), W-3's expand function is taken over by the global switch, and W-4 (source-clip secondary duration) has landed. Three later batches filled in W-5 through W-10, and the W-11 platform-difference ruling was completed (§8.4). For implementation, transaction boundaries and verification, see [`apps/web/docs/talking-head-cut.md`](../../../../apps/web/docs/talking-head-cut.md).
