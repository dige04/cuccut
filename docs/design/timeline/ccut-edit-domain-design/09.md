# 9. Milestones

> From [CucCut Edit Domain Protocol Design (Cut / Clip / Element / Watermark / Project Export)](../ccut-edit-domain-design.md)

Implementation status (updated after the 2026-08-02 review): the in-repo implementation of E0–E4 is complete. On 2026-08-02 the protocol was fully audited against this document, and a batch of semantic gaps was fixed: normalization of the word-cut midpoint rule, WordSpan frame-alignment order, stale scans after transactions, protection of manual translations, lossy computed values, lint without fail-fast, contract fixtures with 10ms samples, Swift views-driven tests, and others (see git history). `ccut-timeline` freezes the two-layer schema, the mappings, the cut/orchestration/element/animation model, and the contract fixtures for all three ends. CLI/serve/Studio/Mac use the same `timeline.json` source of truth and the same history transactions. Native MP4 export handles clip×kept multi-source main picture, audio mixing, and full overlay of shared DrawOps. `ccut-editable`, the export registry, the CapCut portable/install writers and the other five writers are all wired up, and the six targets share one OUTPUT IR and preflight. The legacy project migrator, the public skill editing surface, cross-source translation of the final timeline, visible-word fingerprints, source-level scatter writes and edit routing have also landed.

**Honest boundary** of client integration (see the gap list in §11 for details): Studio Web already has segment-jump playback, timeline projection consumption, and cross-source translation edit routing, but **the clip-editing UI and the `timeline/apply` calls have not landed yet**. The Mac editor write path still goes through the whole-document `replaceTimeline` commit (fine-grained ops are not wired up). The native player already uses `TimelineMapping.swift` to map OUTPUT seek/clock readback to the source/kept segment of the current clip; it skips source cuts and crosses clip in-points within the same media. Switching the AVPlayer media across different `srcId`s is still pending. Soft-delete write-back still turns a cut clip into a clip removal rather than a `sources[].cuts` entry.

The repository regression suite includes VoiceInk `EditableTimelineBuilderTests`, CapCut calibration/defect samples, FCP7, FCPXML and MLT golden tests, single-layer→two-layer fixtures for legacy projects, the six-target registry/finish-check, and Rust/JavaScript/Swift timeline projection cross-checks. Opening the generated projects in the specific installed CapCut/剪映, Premiere, Resolve, Final Cut Pro, Shotcut and Kdenlive versions is still external acceptance testing for the release candidate. This round has no production release authorization, so it is not reported as having been executed.
