Risks and mitigations:

- **The atomize quality for Chinese word segmentation** determines the LCS mapping success rate. In P1, first port voice-ink's `SubText.atomize` (CJK character by character + Latin words) and cross-check it against its test set; do not build a tokenizer from scratch;
- **The Rust side has no ready-made LLM SDK dependency**. This is deliberate: a request is just a POST with JSON, and `ureq` is enough. Streaming (progress and sub-second cancellation) is deferred; evaluate `reqwest` only when needed;
- **In agent mode, the lint is the engine validation**. The same validation code must be shared by both executors, otherwise the output quality of the provider and agent paths will drift apart.
