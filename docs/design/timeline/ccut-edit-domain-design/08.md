# 8. Skill editing-surface regression

> From [CucCut editing-domain protocol design (Cut / Clip / Element / Watermark / Project export)](../ccut-edit-domain-design.md)

`skills/cuccut/` has had the editing noun group added back, using the established mechanism in [§6.1](../../../archive/mac/ccut-mac-app-port-design.md):

- The routing table adds `cut / clip / element / broll / watermark / screentext / animation / frames`, all generated from the actual `ccut spec` (no unimplemented capabilities are promised);
- Reference docs such as `references/editing.md` are rewritten to follow this protocol. Older docs contain statements such as `doc.broll` that have drifted from the implementation, so they are not copied as-is. **The two-layer model (cut belongs to media, clip belongs to the timeline, restore takes a cutId) is a semantic change that must be explained clearly to the Agent**;
- Bumping the major version restores the capability surface of the 0.9.x era, and the README notes the differences from the old command surface.
