# 7. Legacy project clip data backfill migration

> From [CucCut clip domain protocol design (Cut / Clip / elements / watermarks / project export)](../ccut-edit-domain-design.md)

`ccut upgrade-cuccut` already implements the in-place upgrade. The old `import-cuccut` is kept only as a hidden compatibility alias. The placement and execution mechanism of the migration (silent in-place upgrade, `archive/` archiving, subtitle-style backfill) is specified in [ccut-legacy-upgrade-design.md](../ccut-legacy-upgrade-design.md). The field-mapping rules in this section remain in effect. The old single-level partitioning is **split into two levels** under the new model:

| Legacy doc.json | New placement | Notes |
| --- | --- | --- |
| Entries in `clips[]` with `cut: true` | `sources[srcId].cuts[]` entry `{t0: src, t1: src+(end-start)}` | Cuts stay within their source (decision 10). Entries in `ai/cuts.json` get `ref` backfilled by matching on id. |
| Kept entries in `clips[]` | `clips[]` entry `{srcId, in: src, out: src+(end-start)}` | Array order is taken by sorting on the old start. Adjacent seamless kept segments from the same source **stay separate** (the old structure is preserved; merging is an editing action). |
| `sources[]` | `sources` table | `media/`-relative references stay unchanged; absolute paths keep external-reference semantics; resources are not copied. |
| `tracks[].elements[]` (including the legacy texts/broll/watermarks projections) | `tracks[].elements[]` | Fields are essentially 1:1 (% coordinate semantics are the same and fold into `place`). Element start/end are converted from old timeline coordinates to new timeline coordinates (through the old partition folding map). The implicit canonicalRank is materialized as an explicit array order. |
| Elements with `kind: sticker/shape/motion` | **Not migrated**; each one is logged explicitly in `migration.json` | Outside the first-release closed element set (§11). |
| `source:"html"` watermark | Its rasterized PNG goes into an image element; `html` is discarded and stated explicitly | Decision 7. |
| `anim {enter/exit/loop}` | Same-named slots in `animate` | Preset ids carry over directly under the same name; `spring` ease → `easeOutBack`; `tracks: [CompiledEffect]` override forms are not migrated (stated explicitly). |
| `ai/cuts.json` / `screentext.json` / `ai/broll-suggestions.json` | New format written to compatible locations; old files archived | Provenance and ticket trail continue. |
| `doc.main` / `videoTrackMuted` | `main` section | — |

Migration is re-entrant, and a failure in one project does not block the others. The mechanism follows [§4.6](../../../archive/mac/ccut-mac-app-port-design.md). The repo fixture `core/fixtures/legacy-upgrade/appdata/` covers the legacy index, doc, flat subtitle styles, subtitle tracks, and fields with explicit loss. The Rust dry-run regression verifies structured loss reporting and zero writes. Other checks cover the in-place final state, cancel/kill -9 resume, timeline mapping, and cross-checking the Rust/Swift style contract.
