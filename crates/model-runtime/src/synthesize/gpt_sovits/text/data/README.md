# Embedded data

All `*.z` files in this directory are zlib (deflate)-compressed. At runtime they are decompressed with `flate2::read::ZlibDecoder` and embedded into the binary via `include_bytes!`.
All of them are generated by `gen_jieba.py` and `gen_data.py` under `scripts/dev/gpt-sovits-text/` in the v2 repository (`cuccut-app`). **Do not edit by hand.** `../symbols.rs` is also generated by `gen_data.py`.
v3 carries over the files from v2 `ccut-tts/src/gpt_sovits/text/data/` unchanged (byte-identical). The generator was not carried over into v3.

## Regenerating

Run these in the v2 repository (`cuccut-app`). For the upstream source, the venv and the NLTK data setup, see `scripts/dev/gpt-sovits-text/README.md` there.

```bash
python scripts/dev/gpt-sovits-text/gen_jieba.py
GSV_UPSTREAM=… NLTK_DATA=… python scripts/dev/gpt-sovits-text/gen_data.py
```

After changing the data, update the SHA-256 values in the table below. `cargo test -p model-runtime synthesize::gpt_sovits::text` cross-checks them.

`g2p_gru.f32` is float weights, which are almost incompressible, so it is not zlib-compressed.

The script reproduces `lazy_pinyin` with a compact table and cross-checks it against the real pypinyin on all 47,111 phrases and 20,000 random strings. Any mismatch fails the build.
