The two key gaps identified when the project was launched are listed below. Both are now closed.

1. **Word timestamps and speaker labels are disjoint.** The Qwen3/Whisper path has word-level timestamps but no speaker labels. The MOSS path has speaker labels but no word timestamps. `refine_word_timings` in `refine.rs` was written to backfill word timings for MOSS lines, but the production path does not reference it.
2. **LLM post-processing was entirely absent.** Polishing, segmentation, chapters and translation had only command planning, with no production implementation.

## 1.2 Scope of this plan

This plan defines all AI stages from the "raw ASR lines" to "exportable bilingual subtitles":

- **Word-level alignment** (stage 0): unify the outputs of both ASR paths into the §18 word-atom transcript;
- **Polishing** (stage 1): the LLM fixes typos, adds punctuation, and splits sentences and paragraphs by semantics;
- **Segmentation** (stage 2): paragraph structure is written into the `paraBreaks` override table;
- **Chaptering** (stage 3): the LLM sets chapter boundaries over the paragraph sequence and writes back `chapters`;
- **Translation** (stage 4): whole-sentence translation plus incremental re-translation;
- **Display splitting and alignment** (stage 5): within each Sentence, translated text is split into lines independently and anchored by word timing, producing bilingual subtitles.

**Non-goals**: selecting a standalone diarization model (the transcription porting plan has deferred it until after P5), GUI integration, and the BCF rendering domain (the consuming side of `from`-derived subtitles is in format spec §8.4; this plan only prepares the transcript-side data).
